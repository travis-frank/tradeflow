# tradeflow.ai

Production financial data platform — real-time stock and crypto prices,
fundamentals, technical indicators, AI research agent, and portfolio analytics.

> Under development

## Stack
- **Backend**: Python 3.11, FastAPI, TimescaleDB, Redis, Celery, LangGraph
- **Frontend**: React 18, TypeScript, Vite, Tailwind, TradingView Charts
- **Infra**: Docker, GitHub Actions, AWS ECS, Datadog
